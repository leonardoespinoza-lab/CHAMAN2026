# SEGURIDAD AUTH

Repo piola para autenticación dentro de proyecto Novit

## Paquetes para CODEGEN

### Paquetes normales

`yarn add graphql-request graphql`

### Paquetes solo dev

`yarn add -D @graphql-codegen/cli @graphql-codegen/typescript-graphql-request @graphql-codegen/typescript-resolvers @graphql-codegen/typescript-document-nodes`

## Init de CODEGEN

`yarn graphql-codegen init`
